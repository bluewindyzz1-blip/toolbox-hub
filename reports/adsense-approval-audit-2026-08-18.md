# 도구상자 AdSense 단독 승인 사전 점검

## 공개 페이지 관찰

2026-08-18에 `https://carculate.moneyko.co.kr/`를 확인했다. 홈에는 생활 계산기, PDF·이미지·문서 변환, 단위 변환의 명확한 대분류가 있으며, 퇴직금·연봉 실수령액·월급 실수령액·실업급여·연말정산·D-Day·월세·대출 이자·부가세 등 실제 계산기를 직접 연결한다. 이미지 회전·반전·흑백·여백 추가와 JPG·PNG·WebP 변환처럼 기능 결과가 명확한 브라우저 내 변환기도 연결된다.

홈 하단에서 이용방법, FAQ, 개인정보처리방침, 이용약관, 면책조항, 쿠키·광고 안내, 문의 페이지로 이동할 수 있다.

## 개인정보처리방침 관찰

`/privacy`는 브라우저 내 파일 처리, 계산기 입력값의 로컬 사용, 문의 메일 방식, 광고·분석 서비스의 쿠키 사용 가능성을 설명한다. 실제 파일이 서버·스토리지로 전송되지 않는다는 내용과 광고·분석 방식이 변경되면 문서를 갱신한다는 문구가 공개돼 있다.

## 초기 판단

공개된 실제 기능과 정책·문의 접근성은 단독 승인 심사에 긍정적이다. 다만 금융·세금·건강 관련 페이지의 기준일·공식 근거·참고용 한계가 페이지마다 일관되게 충분한지, 쿠키·광고 안내의 Google 정책 연결이 명확한지는 이어서 확인해야 한다.

## 쿠키·광고 안내 관찰

`/cookie-policy`는 실제 환경변수에 AdSense 게시자·슬롯 ID가 설정될 때만 광고가 활성화된다는 점, 광고 기술이 쿠키 또는 유사 기술을 사용할 수 있다는 점, 광고와 콘텐츠를 구분하고 광고 클릭을 유도하지 않는다는 점을 공개한다. 기본 고지와 광고 배치 원칙은 갖췄다. 다만 실제 Google의 데이터 사용 안내 링크와 지역별 동의 처리 방식은 광고·방문자 규모가 커지기 전에 더 구체화하면 좋다.

## 대표 계산기 관찰

`/calculator/salary/monthly-take-home`에는 실제 입력 폼과 계산 결과, 공제 항목별 결과, 계산 공식·방법·예시·주의사항·사용 상황·결과 해석·공식 참고자료·FAQ·관련 도구가 공개돼 있다. 이는 단순 키워드 페이지가 아니라 실제 기능과 자체 설명을 가진 페이지라는 강점이다. 화면상 광고 영역은 입력·결과 카드와 별도 위치에 있고 `ADVERTISEMENT`라고 구분돼 있다. 페이지는 개인별 조건 차이와 참고용 간이 계산이라는 한계를 명시하며 고용노동부 공식 사이트를 연결한다.

## 업데이트된 초기 판단

대표 페이지 표본은 유틸리티 사이트의 독창적 기능, 사용자에게 공개된 설명·FAQ, 금융성 계산의 한계 고지, 공식 외부 참고 링크를 모두 갖췄다. AdSense 단독 승인 자체를 막는 명백한 저가치 페이지·기능 부재·정책 페이지 부재 징후는 이번 표본에서 확인되지 않았다. 다만 금융·세금 기준의 정기적 갱신 가능성, 일반 정보 페이지의 깊이, 광고 정책 고지의 외부 링크는 승인 가능성을 높이는 개선 포인트다.

## 공식 기준 대조

Google은 AdSense 참여 전 고품질·독창적이고 방문자를 끌어들일 수 있는 자체 콘텐츠, 정책 준수, 사이트 HTML 수정 권한을 요구한다.[1] 사이트를 추가하면 Google은 도메인 소유·수정 권한과 프로그램·게시자 정책 준수 여부를 확인하며, 완료에는 일반적으로 며칠에서 2~4주가 걸릴 수 있다.[2]

Google은 승인 보류의 일반 사유로 콘텐츠 부족, 독창적·풍부한 콘텐츠 부족, 정책 위반, 탐색 문제, 부적절한 트래픽 소스, 지원하지 않는 언어를 제시한다. 심사는 신청 URL만이 아니라 사이트의 모든 페이지를 볼 수 있다고 설명한다.[3]

## 최종 견해

이 사이트는 **단독으로 AdSense 사이트 심사를 받을 수 있는 상태에 가깝고, 신청 자체를 피해야 할 명백한 결함은 보이지 않는다.** 특히 단순 링크·복사 콘텐츠 사이트가 아니라 작동하는 계산·변환 기능과 사용자 설명·정책 문서를 갖춘 점이 장점이다.

다만 ‘무조건 승인’이라고 말할 수는 없다. Google은 사이트 전체를 검토하며 승인 결과와 세부 사유는 Google이 결정한다.[2] 나의 실무적 권고는 다음과 같다.

1. 월급·연봉·퇴직금·대출·전월세·세금·PDF 도구 등 대표 6개 페이지의 기준일·공식 링크·참고용 한계를 한 번 더 빠르게 점검한다.
2. 쿠키·광고 안내에 Google 파트너 데이터 사용 안내 링크를 추가하고, 유럽 경제 지역·영국·스위스 방문자가 의미 있게 발생하면 Google CMP 적용 여부를 검토한다.
3. 큰 구조 변경을 더 하지 말고 7~14일간 Search Console·Vercel Analytics에 오류가 없는지 확인한 뒤, 단독 사이트 URL을 AdSense Sites에 추가해 검토를 요청한다.
4. 심사 중에는 전면 광고·과도한 광고 슬롯·제휴 링크를 늘리지 않는다. 실제 도구 결과와 설명이 광고보다 먼저 보여야 한다.
