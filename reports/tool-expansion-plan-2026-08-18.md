# 도구상자 40종 확장 설계

## 선정 기준

기존 카탈로그의 55개 계산기와 28개 파일 변환기를 전수 확인해 URL·기능이 중복되지 않는 항목만 선정했다. 후보는 국내 생활 계산 서비스의 금융·날짜·자동차·생활 수요 범주와, 브라우저에서 파일을 전송하지 않고 처리하는 PDF·이미지 작업 흐름을 참고했다. 이번 추가분은 외부 API나 로그인 없이 모두 브라우저에서 실제 동작하도록 구현한다.

참고한 공개 서비스: [K-Calculator](https://k-calc.com/), [iTool Image to PDF](https://itool.co.kr/en/pdf/image-to-pdf/), [Google Play 생활 금융 계산기](https://play.google.com/store/apps/details?id=com.tha.lifefinancecalc&hl=ko).

## 구현 원칙

계산기는 `shared/toolbox.ts`의 순수 함수와 `DailyWorkCalculators.tsx`의 공통 입력·결과 UI를 확장한다. 변환기는 새 `TextTransformTool.tsx`에서 20개 모드를 제공하고, 카탈로그 라우터에서는 슬러그별 초기 모드만 전달한다. 각 신규 항목은 고유한 한글 제목·설명·검색어·관련 도구·SEO 제목과 설명을 가진다. 사이트맵과 prerender 출력은 기존 생성 스크립트가 카탈로그를 읽으므로 신규 도구가 등록되면 자동 포함된다.

## 검증 범위

각 계산 순수 함수는 단위 테스트로 정상값·경계값·유효성 실패값을 확인한다. 텍스트 변환기는 대표 입력과 유효하지 않은 JSON·Base64·URL 인코딩 오류를 확인한다. 이후 TypeScript 검사, 전체 테스트, Vercel Production 빌드, 정적 SEO 검증, 주요 신규 URL의 브라우저 동작을 순서대로 점검한다.


## 로컬 브라우저 확인

Vite Production 미리보기에서 신규 단가 계산기 `/calculator/lifestyle/unit-price`가 고유 title·breadcrumb·입력·결과·공식·주의사항·관련 도구를 포함해 정상 렌더링되는 것을 확인했다. 기본 예시 18,000원 ÷ 12개의 결과는 1,500원으로 표시됐다.

신규 JSON 정리 페이지 `/convert/text/json-pretty`는 `텍스트·웹 변환` breadcrumb, 20개 변환 탭, 입력·결과 영역과 브라우저 내 처리 고지를 포함해 정상 렌더링됐다. 제목은 `JSON 정리 | JSON 예쁘게 정렬 | 도구상자`로 확인했다.
JSON 정리 화면에서 기본 예시로 변환 버튼을 실행하는 브라우저 검증을 시작했다. 화면의 입력·탭·버튼 렌더링은 정상이며, 결과 텍스트 영역 갱신 여부는 DOM 값으로 추가 확인한다.
JSON 정리 버튼을 자동 브라우저 클릭으로 실행한 직후 결과 textarea의 DOM 값은 비어 있었고, 콘솔에는 변환 오류가 기록되지 않았다. 입력값과 변환 버튼은 각각 DOM에서 정상 확인됐다. 다음 검증에서는 같은 버튼의 프로그램적 클릭으로 이벤트 연결을 확인한다.
프로그램적 클릭 후 렌더링 완료 시점을 다시 확인한 결과, JSON 정리 결과 textarea에 들여쓰기된 JSON이 정상 표시됐다. 초기 자동 클릭 직후에는 React 상태 갱신 전 값이 관찰된 것이며, 실제 변환 이벤트와 결과 화면은 정상 동작한다.
